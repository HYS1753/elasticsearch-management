# AI Agents Knowledge Base

This directory (`.agent/knowledge/`) stores specific knowledge documents generated by or for the AI Agent cluster.

## Purpose
When working on complex modules (e.g., a specific set of log index templates or a complex nested mapping), you can create an agent-specific markdown file here to store long-term context, preventing the need to re-read the entire codebase.

## Example Usage
- `logging_knowledge.md`: Knowledge regarding log rotation, timestamp mappings, and ILM policies.
- `security_knowledge.md`: Context regarding audit logs and role-based access control mappings.
