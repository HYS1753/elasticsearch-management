# Project Map (map.md)

This map is used by AI Agents to quickly route to relevant sections of the repository.

## Directory Structure
- `/management_api`: Backend API service handling Elasticsearch and database logic.
- `/management_ui`: Frontend Next.js interface for managing Elasticsearch.
- `/.agent/skills`: Custom instruction skills for AI agents.
- `/.agent/knowledge`: Shared agent knowledge bases.

## Key Files
- `AGENTS.md`: Core rules and constraints.
- `ARCHITECTURE.md`: Structural design and submodule boundaries.
- `WORKFLOW.md`: Steps to create/modify/verify templates and features.
