# Project Map (map.md)

This map is used by AI Agents to quickly route to relevant sections of the repository.

## Directory Structure
- `/component_templates`: Reusable Elasticsearch mapping and setting blocks.
- `/index_templates`: Final templates composing components, matching index patterns.
- `/.agent/skills`: Custom instructions for handling Elasticsearch tasks.
- `/.agent/knowledge`: Module-specific knowledge bases for different parts of the cluster configuration.

## Key Files
- `AGENTS.md`: Core rules and constraints.
- `ARCHITECTURE.md`: Structural design and mapping strategies.
- `WORKFLOW.md`: Steps to create/modify templates.
